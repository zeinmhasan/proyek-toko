# Toko Management System

Website manajemen toko yang terintegrasi dengan berbagai fitur untuk mengelola bisnis Anda.

## Fitur Utama

- **Kasir**: Kelola transaksi penjualan
- **Kelola Barang**: Manage inventory dan stok
- **Pemasukan & Pengeluaran**: Monitor arus kas
- **Catatan Hutang**: Kelola hutang piutang

## Tech Stack

- React 18
- TypeScript
- Tailwind CSS
- Vite

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```
